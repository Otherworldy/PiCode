# 桌面应用更新

设置页「关于」提供当前版本、更新检查，以及桌面安装包的下载和安装。Web 只显示版本，不提供安装。

## 所有者

桌面主进程的 `AppUpdateController` 是唯一状态所有者。渲染进程只保存它广播的快照，不另记一份下载进度或已选安装包。

## 规则

- 更新源是公开仓库 `Otherworldy/PiCode` 的最新正式 GitHub Release（不含 draft、prerelease）。
- 当前版本大于或等于发布版本时，结果是已最新。开发态用仓库根 `package.json` 的版本，不用 Electron 运行时版本。
- 安装包按本机系统选择：Windows `.exe`、macOS `.dmg`、Linux `.AppImage`。同名测试包（`_TEST`）只在没有正式包时才被选中。
- 未打包的开发进程可以检查，但不能下载或安装。
- 手动发起的新检查会作废进行中的下载。过期下载不能改写新检查的结果。重新打开「关于」时，如果下载或安装还在进行，只恢复当前进度，不重新检查。
- 检查和下载读取设置页当前的 HTTP 代理、No Proxy 和自定义 CA。未配置代理时直连。
- 安装：
  - Windows：启动已下载的安装程序，然后退出当前应用。
  - macOS：打开 dmg，应用保持运行，由用户拖入「应用程序」。
  - Linux：若当前是 AppImage，则替换 `APPIMAGE` 指向的文件并重启；否则启动下载到的 AppImage。

## 失败

网络、没有发布、没有匹配安装包、下载失败、安装失败都回到 `error`，并带稳定错误码。失败不修改当前已安装的应用。
