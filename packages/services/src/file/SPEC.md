# 工作区文件搜索忽略

`.picodeignore`（workspace 根目录，gitignore 语法）是 @ 候选、Command Center、文件树搜索的唯一忽略规则。不影响 git、文件树浏览、上传或 Agent 读文件。

## 所有权

| 状态                         | 所有者                             |
| ---------------------------- | ---------------------------------- |
| 搜索忽略规则正文             | workspace 根目录的 `.picodeignore` |
| 读取、缺失时创建、设置页读写 | `workspaceFileIgnore.ts`           |

`fileService` 只消费解析后的规则与该文件的 mtime/size 指纹，不另存一份规则。

## 迁移

只在 `.picodeignore` 不存在且 `.zcodeignore` 存在时，把旧文件 `rename` 为 `.picodeignore`。两者都在时保留新文件，不覆盖、不删除旧文件。`rename` 失败（占用或权限）则继续读旧路径，不另写一份模板把自定义规则盖掉。下次加载会再试一次改名。

## 失败

读或创建失败时，内存中改用 `.gitignore`，再失败用内置默认规则。搜索不因此失败。

## 验收

1. 只有 `.zcodeignore` 时，读取后磁盘上变为 `.picodeignore`，内容不变，旧文件消失。
2. 两者都在时，读到的是 `.picodeignore`，`.zcodeignore` 仍在且内容不变。
3. 都没有时，扫描创建 `.picodeignore`，不创建 `.zcodeignore`。

# 系统提示词

Pi 的系统提示词正文只在这两个文件里。设置页和项目按钮只读写文件，不另存一份。`kind` 缺省是 `replace`。

| kind      | 文件               | 行为                           |
| --------- | ------------------ | ------------------------------ |
| `replace` | `SYSTEM.md`        | 有内容时整段替换内置系统提示词 |
| `append`  | `APPEND_SYSTEM.md` | 追加在已经确定的系统提示词后面 |

| 范围 | 路径                                                                                                      | 谁写                                            |
| ---- | --------------------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| 全局 | `<agent-dir>/SYSTEM.md` 或 `APPEND_SYSTEM.md`。`agent-dir` 优先 `PI_CODING_AGENT_DIR`，否则 `~/.pi/agent` | 执行读写的那台 Host 的本机磁盘                  |
| 项目 | `<workspace>/.pi/` 下的同名文件                                                                           | 该工作区的 file service（本机、远端服务或 SSH） |

同名文件项目优先于全局，两份不合并。`SYSTEM.md` 和 `APPEND_SYSTEM.md` 不是同名，会叠在一起：先确定替换段，再追加追加段。

路径、空白删除和 256 KiB 上限在 `@zcode/shared/node` 的 `agentSystemPromptFile`。本地落盘在 `agentSystemPrompt.ts`。

只含空白的保存删掉文件。空的 `SYSTEM.md` 仍会替换内置提示词，空的 `APPEND_SYSTEM.md` 仍会占掉追加位。超过 256 KiB 拒绝写入，也不把已有超限文件截断后交给编辑器。

已打开的会话不热更新。下一次新建或重新打开会话时，Pi 的 resource loader 重新读文件。SSH 工作区的项目文件在远端；会话创建时若远端 `SYSTEM.md` 存在，用它覆盖本机按 cwd 发现的替换段。远端 `APPEND_SYSTEM.md` 存在时作为项目追加，不再使用本机发现的同名文件。SSH 工作区说明和懒加载 Chrome 提示接在这份追加之后，不替换它。

# 提示词模板

Pi 的可复用提示词是多份文件，不是一份 `SYSTEM.md`。

| 范围 | 目录                           |
| ---- | ------------------------------ |
| 全局 | `<agent-dir>/prompts/*.md`     |
| 项目 | `<workspace>/.pi/prompts/*.md` |

只认这一层目录里的 `.md`。文件名去掉后缀就是斜杠命令，例如 `review.md` 对应 `/review`。子目录、隐藏文件和带 `..` 的名字不列出、不写。空文件可以保留。超过 256 KiB 拒绝写入。设置页和项目按钮只通过 file service 读写这些文件。设置页用三个页签编辑全局的 `APPEND_SYSTEM.md`、`SYSTEM.md` 和 `prompts/*.md`。项目按钮编辑该工作区的同名文件。列表显示完整文件名，不带 `/`。

斜杠菜单列出时会再扫这两个目录。已经打开的会话只提供扩展命令和它创建时载入的模板，不能挡住后来保存的文件。保存后再打开 `/` 就能看到新命令，不必重启，也不必另开会话。当前会话还没载入这个文件时，发送 `/name` 按磁盘上的模板展开。删掉的文件仍留在已经载入它的会话里，直到那个会话结束。
