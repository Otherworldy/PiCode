# 侧栏顶部入口

侧栏顶部是工作区主视图的入口，不是设置页分区。

- 「To-Dos」打开 To-Dos 主视图。
- 「自动化」打开自动化主视图。这一页同时承载定时任务、闲时任务，以及动态工作流灰度开启时的「工作流」标签。侧栏不另放「工作流」按钮。
- 当前主视图是自动化时，这个入口保持选中。再点一次仍走原来的导航；相邻的同一目标不会重复入栈。
- 设置页不再提供「自动化」分区。灰度关闭时页内没有「工作流」标签，入口仍然在。

# 项目提示词

每个已连接的工作区行，在文件树按钮旁有一个图标。对话框有三个并存页签，都只改这个工作区，不打开设置页，也不改全局文件。

| 页签           | 文件                   | 行为                                                   |
| -------------- | ---------------------- | ------------------------------------------------------ |
| 追加系统提示词 | `.pi/APPEND_SYSTEM.md` | 追加在已经生效的系统提示词后面                         |
| 系统提示词     | `.pi/SYSTEM.md`        | 有内容时整段替换全局和内置系统提示词                   |
| 斜杠命令模板   | `.pi/prompts/*.md`     | 文件名去掉后缀是斜杠命令。列表显示完整文件名，不带 `/` |

页签标题只有名称，不带文件名徽章。底部一个保存只写当前页签。空白保存会删除 `SYSTEM.md` 和 `APPEND_SYSTEM.md`。切换页签、切换模板或关闭对话框时，未保存修改要先确认放弃。

断连的远端工作区不显示这个按钮。本地目录不可用时按钮禁用。文件由该工作区自己的 file service 写入。两份系统提示词下一次新建或重新打开会话才生效。斜杠命令保存后，再打开 `/` 就能用，不必重启。

# 项目 MCP

每个已连接的工作区行，在项目提示词按钮旁有一个图标。它只管理该工作区的 `.pi/mcp.json`（Pi 的项目 MCP，`mcpServers`）。不打开设置页，也不改全局 `~/.pi/agent/mcp.json`。插件 MCP 和 `.agents/mcp.json` 不在这里编辑。

断连的远端工作区不显示这个按钮。本地目录不可用时按钮禁用。读写走该工作区自己的 MCP 同步服务。保存后，下一次新建或重新打开会话才生效。项目里的同名条目覆盖全局条目。

这个对话框用自己的列表，不把别的工作区写进当前 MCP 投影。只有投影已经是这个工作区时，保存后才刷新它。

打开对话框只读 `.pi/mcp.json` 并立刻显示列表，不等待、也不发起连接测试。连接测试只在用户点刷新后进行：列表保持可见，再把已启用的用户级服务器和这个项目的条目一起交给 MCP 同步服务。只提交项目条目会让同一条连接池按 replace 断开其余服务器。状态写回对话框自己的列表。

设置页的 MCP 分区同样不在打开或切换工作区时自动 connect。用户点刷新，或在设置里启用一台服务器时，才做连接测试。
