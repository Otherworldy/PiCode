# 桌面宠物

桌面端可选模块。默认关闭，安装包不带宠物资源，也没有内置宠物。

## 行为

- 桌面端设置里有独立的「桌面宠物」页。Web 和手机不显示这一页。基础设置包含「启用桌面宠物」和「气泡底色」。下方为卡片化「桌面宠物列表」，直观展示已下载和本地导入的角色卡片，每张卡片呈现第一只宠物的名字、尺寸、来源标签、待机 WebM 动作素材预览与当前使用状态。
- 宠物列表头部提供「导入宠物」、「下载宠物包」与「重新扫描」：
  - 「导入宠物」：用户选择本地文件夹，主进程校验其包含可解析的 dsh 配置文件与动画后，加入已导入列表（记录于 `pets/imported.json`）并自动应用。
  - 「下载宠物包」：打开下载弹窗，在弹窗里填写 http(s) zip 地址、快捷填入推荐地址 `https://pub-4de328cc5516482d80f6e14e6829136d.r2.dev/dsh-pet.zip`，并实时展示下载与解压进度，支持中途停止。常规设置里的 HTTP 代理、不使用代理的地址和自定义证书同样用于下载。下载完成后自动扫描并加入卡片列表。
  - 卡片支持「应用」与「删除」：
    - 点击「应用」：切换为当前使用宠物。本地宠物将设置记为本地目录并清空下载地址；下载宠物将设置记为该包来源地址并清空本地目录。
    - 点击「删除」：弹出二次确认。若是本地导入宠物，仅解除关联并从列表中移除，不删除本地磁盘上的物理文件；若是下载包，彻底删除 `pets/packs/<id>` 下的物理文件和缓存。删除当前使用的宠物时同步重置活跃宠物配置。
- 下载的 zip 和解压结果写到安装目录下的 `pets/packs`。不写到系统用户目录。开发态没有安装目录时，写到应用目录下的 `pets`。
- 资源必须是 dsh-pet 兼容包：`config.jsonc` / `*-config.json(c)` 里的 `animations`，以及同包里的透明 WebM。
- 只使用第一只宠物。播放池包括待机、转向、移动、分类小动作、点击和拖拽片段。
- 窗口是「角色舞台 + 气泡」的并集，四边再留 4px 透明边给投影。缺省气泡宽取宠物 `size` 减两边各 8px，底边在角色顶边上方 6px，高 76px（4 行正文）。角色区域默认裁到角色真正占用的像素：渲染端在每段动画第一帧量出上下左右第一个不透明像素，再乘上显示缩放。dsh 包常见是 640×360 的帧、角色只占中间约 213×267，所以 `size` 320 时角色看着约 107×137，窗口约 312×227。量不到像素时退回整帧。量到的框记在 `pets/box.json`，下次启动直接按它建窗口，不用等渲染端再报一遍。窗口涨缩时角色在屏幕上不动，只有多出来的透明区域变。
- 裁剪在设置里默认开启，可以关。关掉后按动画原本的构图：舞台上就是整帧，上下那圈透明区域回到可点范围，缺省气泡浮在整帧上方。
- 点击、拖拽和右键只认角色区域：裁剪开启时视频自带的透明留白不属于宠物区域，点在留白上不触发点击反应。
- 窗口比角色宽是给气泡留位置，角色两侧的空白不接管桌面点击：播放页把角色和气泡的矩形报给主进程，主进程用 `setShape` 把窗口形状裁成这两块，形状外不绘制也不接收鼠标事件，点击直接落到桌面上。布局变化、气泡显隐和换片段都会重报，拖动时形状跟着窗口走。编辑态临时恢复整窗，好拖白框和气泡。macOS 不支持窗口形状，只能整窗吃点击。
- 显示大小可在设置里选（50%–150%，缺省 100%）。它乘在角色像素上，窗口跟着变；气泡大小不受影响。
- 摸鱼气泡的大小和位置可以自定义，只作用于摸鱼正文，消息提醒气泡始终按缺省摆放。设置页的「在桌面上调整」把宠物窗口临时铺到工作区，角色原位不动：拖气泡移动、拖蓝色手柄缩放；拖白框裁剪角色舞台，白框外压暗，方便看清裁掉哪块。画布同时用蓝虚线画出保存后的窗口范围。回车或点「保存」落盘，Esc 或「取消」还原。几何存成相对角色脚底中心的 `{x,y,w,h}`，所以换宠物、换缩放、换包之后摆放关系不变；所有宠物共用一套。高度按当前行高整行吸附，保存时正文区是行高的整数倍。
- 舞台裁剪存成相对视频帧的比例 `{x,y,w,h}`，所有片段共用一块裁剪，换动作时角色不会忽大忽小；舞台尺寸按裁剪和显示缩放算，不再依赖逐帧量到的像素。只有真的拖动过白框才写这块裁剪，否则继续按每段动画自动量，避免把一个动作的框写死、把别的动作切掉。设置页可以「恢复默认」把气泡和舞台一起回到自动。
- 随机链权重与 dsh 相同：`idle` / `turn` / `move` 加上分类权重；`fixedEnabled` 时不抽转向和移动。
- 点击播 `clicks`。拖拽时播 `drag`，松手回到随机链。移动片段只在原地播放，不漫游。
- 右键弹出动作菜单，按待机、转向、移动、点击、拖拽和各分类列出已加载片段。点一项只播一次，然后回到随机链。转向播完仍翻转朝向。空分组不出现。
- 任务通知不看窗口是否聚焦。宠物可用时用气泡和工作状态动画呈现，并保留点按回到该任务。气泡贴在角色上方；关掉裁剪时浮在整帧上方。气泡底色可在设置里选黑底或白底，缺省黑底。资源不可用时走系统通知。
- 宠物心情跟着会话列表走，不另向模型要动作。一只宠物看所有窗口报上来的会话，不跟某一条会话。优先级是等人、思考、忙碌，然后才是随机待机。等人用工作状态槽 3，思考用槽 0，忙碌用槽 1。`running` 和 `prewarming` 都算思考。没有回合在跑但还有后台工作算忙碌。权限或提问算等人。槽是空的就退回下一档，不占用别的槽。思考和忙碌不弹气泡。完成和失败仍是原来的一次性提醒；提醒播完，若还有会话在等、在跑或有后台工作，回到对应心情。拖拽、点击和右键点播结束后也回到当前心情。心情不盖住摸鱼正文。
- 摸鱼文本用同一条气泡，不另开窗口，也不把气泡加大。设置里选一个本地文本，并设快捷键，缺省 F9。快捷键方式可选点击切换或按住，缺省点击切换：按一下打开，再按一下关闭。按住是按下后显示，松开立刻关闭，并且不把宠物窗口拉到前台。全局热键没有松开事件，松开靠轮询按键状态；读不到状态时退回点击切换。按住模式可以打开「自动翻页」：按住期间正文自己往下走，读到页尾自动接下一页，等新页时停住不乱发请求；松手、切到任务提醒或进入编辑态都会暂停，回到正文再从原处接着走。翻页速率直接填每行停留的毫秒数，200 到 20000，缺省 1200；填 0、留空或超出范围都夹到上下限，不会把正文滚成一片残影；点击切换模式没有松手这个动作，所以不提供自动翻页。滚轮在气泡里翻页：滚一格正好一行，并且总是停在行边界上，不会露半行；触控板的小步幅攒够大半行才走一格，到底或到顶再滚才翻页。正文按页从文件里读，不把整本载入内存。设置里可以查找一段文字并跳到那里。PiCode 运行时会占住这个键。任务提醒会暂时盖住正文，提醒结束后正文回到原处。正文排版可调：字号 10–20px（缺省 12）、行距按字号的倍数 1.2–2.0（缺省 1.35）、字间距 0–4px（缺省 0）。行高由字号乘行距取整，整行滚动和气泡高度吸附都以这个行高为准。排版只作用摸鱼正文，消息提醒气泡维持 12px/16px。改排版不动已保存的气泡矩形：气泡宽高不变，窗口不重排，正文和阅读位置留在原处，只把滚动位置对回整行。
- 正常收口走完成提醒。模型报错收成会话 phase `error`，走失败提醒。用户中断仍走完成提醒。
- Web 和手机忽略这些设置。

## 所有者

- 宠物窗、下载缓存、导入记录、当前资源路径和合成后的心情只归桌面主进程。每个窗口只上报自己工作区的心情，窗口关闭后这份上报作废。
- 任务通知事实仍由现有编排产生；宠物只替换展示，不改通知什么时候产生。心情不是通知，不发系统通知，也不在 10 秒后消失。
- 设置只存开关、目录、下载地址、气泡底色、显示大小、裁剪开关、摸鱼气泡矩形、舞台裁剪、摸鱼文本路径、快捷键和快捷键方式、正文字号行距字间距。这些字段同时写在安装目录的 `pets/settings.json`。应用设置被旧进程整份重写、认不出这些字段时，用这份文件恢复，避免设置页回到默认值。下载文件的位置由安装目录决定，不跟用户数据目录走。本地导入记录保存在安装目录下的 `pets/imported.json`。角色像素框记在 `pets/box.json`，按包目录区分。阅读位置是文件里的字节偏移，记在安装目录下的 `pets/reader-place.json`。

## 失败

- 目录或 zip 里没有可播放的动画：不显示宠物，通知回到系统通道，设置页写明压缩包里没有可用配置。
- zip 路径跳出目标目录、超过 512MB 或不是 http(s)：拒绝并保持宠物关闭。设置页写明原因。网络失败或服务端错误同样留在这一行，不只写进日志。
